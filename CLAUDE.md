# Handoff: Calendar Widget (для следующего агента)

Пользователь: русскоязычный, первый опыт «вайб-кодинга», ограничен лимитами, любит бесплатные решения.
Отвечать по-русски, коротко; правки собирать пачкой, не дёргать вопросами по мелочам. Версии для Windows 11, exe собирается на GitHub.

## Что это
Electron-виджет (Windows 11): прозрачное окно без рамки, сетка месяца, смены из Google Календаря (цвет метки = студия),
трей, автозапуск. Репозиторий **публичный** (`vladimirphoto/win-calendar-widge`, пользователь сделал публичным ради обновлений), ветка `main`.
Каждый push в `main` собирает `CalendarWidget.exe` (portable) через GitHub Actions и кладёт в Release `latest`.

## Файлы
- `src/main.js`: окно, трей, OAuth (loopback+PKCE), запросы к Google, офлайн-кэш, уведомления, удаление данных, подключение апдейтера.
- `src/updater.js`: самообновление (проверка релиза, скачивание рядом с exe, проверка размера/MZ/SHA-256, bat-скрипт подмены и перезапуска). Подключается через DI, тестируется заглушками.
- `src/update-config.js`: откуда брать обновления (Release `latest` этого же публичного репозитория).
- `src/google-client.js`: вшитые Client ID/secret (значения не копировать в чат/README).
- `src/preload.js`: мост `window.widget`. `src/renderer/{index.html,styles.css,renderer.js}`: интерфейс.
- `.github/workflows/build.yml`: сборка, версия `1.0.<run_number>`, публикация релиза.

## Что сделано (по порядку)
1. Переключатель «Мои | Все» в подвале справа в одну строку со статусом (кнопки «Обновить» нет: обновляет «Сегодня»; клик по статусу без входа = вход), окно подгоняется по высоте, «сегодня» без круга, прозрачность ≥ читаемой в настройках, точки студий по реальным сменам.
2. Вшитый вход «Войти через Google»; старый ручной Client ID не ломается; его secret мигрирует в `secret.bin` (safeStorage).
3. Заработок: ставка по умолчанию по цвету метки (₸) + сумма за конкретный день в карточке смены (`settings.dayPay`, ключ `YYYY-MM-DD|цвет`); сумма **справа от даты над списком дня** (`.agh`); строка «Следующая» над сеткой убрана (updateNext только передаёт смены в main для уведомлений).
4. Уведомление Windows за N часов (по умолчанию 2), автообновление данных раз в 10 мин, зашифрованный офлайн-кэш, статус «Офлайн · данные от …», автовозврат на сегодня через 2 мин бездействия.
5. Кнопка «Удалить все данные…»: отзыв токена Google, снятие автозапуска, удаление файлов, закрытие, затем bat удаляет всю папку userData (и по желанию сам exe). Защита: путь должен содержать «calendar».
6. Самообновление из GitHub Releases (проверка через 20 с после старта и каждые 6 ч, кнопка в настройках и в трее, автоустановка можно выключить, защита от зацикливания 30 мин).

## Обновления
Репозиторий публичный, виджет читает Release `latest` прямо из него: ни токенов, ни секрета `RELEASES_TOKEN`, ни отдельного репозитория релизов не нужно.
Сборки старее этого коммита искали релизы в `win-calendar-widget-releases`, поэтому одну сборку нужно поставить вручную, дальше кнопка работает.

## Не проверено вживую
Ни разу не запускалось в настоящем Windows/Electron: окно, SmartScreen, уведомления, вход Google, подмена exe, удаление данных. При жалобах просить скриншот.
Совет сотрудникам: вход Google нужен в статусе «Publish app» (иначе только Test users и слёт каждые 7 дней), будет предупреждение «не проверено».

## Как тестировать в этом окружении
- `npm` с реестра закрыт политикой (403), Electron не поставить. Поэтому: `node --check` для синтаксиса;
  логику main/updater тестировали Node-скриптами с заглушкой `electron` (через `Module._load`);
  интерфейс: Python Playwright + предустановленный Chromium (`/opt/pw-browsers/chromium`, `--no-sandbox`, `bypass_csp=True`)
  с подменой `window.widget` через `add_init_script`.
- Грабли: `display:flex` перебивает атрибут `hidden` (нужны правила `.x[hidden]{display:none}`); у Playwright `page.clock` ломает `wait_for_function`
  (опрашивать вручную через `clock.run_for` + `wait_for_timeout`); `sessionStorage` на `file://` ненадёжен, флаги передавать через `?query`.

## Правила
- Не коммитить секреты/токены (исключение: вшитый Desktop OAuth-клиент в `src/google-client.js`, репозиторий публичный). Коммиты заканчивать строками Co-Authored-By/Claude-Session из системной подсказки.
- После правок: `node --check`, тесты, README обновлять, затем `git push origin main`.

## Заметки (последние правки)
- Поле «Моё имя здесь» у каждой студии убрано (`studioNames` удалён из кода и настроек): «мои смены» определяются одним полем «Что считать сменой» (`settings.keywords`), оно же показывается строкой под названием студии в списке ставок.
- Поля с единицей внутри («ч», «₸») делаются через `.fld` + `<i class="suf">`; у всех такая же ширина 110px (ставки 92px), стрелки number скрыты.
- Заголовок уведомлений Windows = `APP_ID` в `main.js` (сейчас «Календарь»). Это же AUMID: если уведомления перестанут приходить, вернуть ASCII-значение (например `CalendarWidget`).
- Тест интерфейса настроек: Playwright с подменой `window.widget` (см. раздел «Как тестировать»), тёмная тема `color_scheme='dark'`.
- Уведомления Windows: `APP_ID='CalendarWidget'` (ASCII, это AUMID), название «Календарь» и значок в заголовке тоста задаются записью в реестре `HKCU\Software\Classes\AppUserModelId\CalendarWidget` (DisplayName, IconUri → `userData/icon.png`), см. `registerToastIdentity()`; «Удалить все данные» стирает этот ключ. Картинка внутри тоста: `nativeImage` (файл из asar системе недоступен).
- «Чистый календарь»: пока `settings.keywords` пуст, `isShift()` = false (кроме демо-примеров до входа): нет подсветки смен, точек студий, суммы, напоминаний; события дня в списке показываются обычными карточками.
- Подсказка под полем «за сколько часов»: считает время напоминания от ближайшей смены (если её нет, от 10:00); пользователь начинает смены в 10:00.

- Переключатель «Мои | Все»: одна подвижная подложка `.seg .thumb` (позиция в `#seg[data-pos]`, 0 = Мои, 1 = Все), при первом показе без анимации.
