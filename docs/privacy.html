Политика конфиденциальности

Calendar Widget (далее «приложение»): настольное приложение для Windows 11. Последнее обновление: 21 октября 2026 г.

Какие данные использует приложение

После вашего входа через Google приложение получает доступ только на чтение к вашим календарям Google (разрешение https://www.googleapis.com/auth/calendar.readonly): названия календарей, их цвета и события (название, дата и время, цвет метки). Эти данные нужны только для того, чтобы показывать вам календарь, смены, заработок и напоминания.

Где хранятся данные

Всё хранится только на вашем компьютере, в папке данных приложения. Токен доступа Google и кэш событий зашифрованы средствами Windows (DPAPI). У разработчика нет сервера, на который передавались бы ваши данные, и нет к ним доступа. Приложение не использует рекламу, аналитику и счётчики, не продаёт и не передаёт данные третьим лицам.

Заявление об ограниченном использовании (Limited Use)

Использование и передача информации, полученной из API Google, соответствует Политике Google в отношении пользовательских данных в API-сервисах, включая требования об ограниченном использовании. Данные используются только для работы функций приложения, перечисленных выше.

Как удалить данные и отозвать доступ

  • В приложении: ⚙ → «Удалить все данные»: стирает настройки, кэш и вход на вашем компьютере и отзывает доступ в аккаунте Google.
  • Или отзовите доступ вручную на странице myaccount.google.com/permissions.

Privacy policy (English summary)

Calendar Widget is a Windows 11 desktop app. After you sign in with Google it requests read-only access to your Google Calendar (calendar.readonly) to display your calendar, shifts, earnings and reminders. All data stays on your computer; the access token and event cache are encrypted with Windows DPAPI. The developer operates no server and has no access to your data; nothing is sold, shared or used for advertising or analytics. The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. To delete data use Settings → "Delete all data" in the app, or revoke access at myaccount.google.com/permissions. Contact: GitHub issues.
