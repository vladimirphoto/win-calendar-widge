Calendar Widget

Прозрачный виджет-календарь для рабочего стола Windows 11: ваши смены из Google Календаря, заработок за месяц и напоминания.

Что умеет

  • Показывает месяц и смены из вашего Google Календаря (только чтение).
  • Считает заработок за месяц по ставкам, которые вы задаёте сами.
  • Присылает уведомления Windows о предстоящей смене.
  • Светлая, тёмная и стеклянная темы.

Скачать

Последняя версия (CalendarWidget.exe). Установка не нужна: запустите файл. При первом запуске Windows может показать предупреждение SmartScreen: нажмите «Подробнее», затем «Выполнить в любом случае».

Доступ к Google Календарю

Приложение запрашивает единственное разрешение: calendar.readonly (просмотр календарей). Данные не отправляются на сервер разработчика: их у разработчика нет. Подробности в политике конфиденциальности.

Исходный код и вопросы: github.com/vladimirphoto/win-calendar-widge.

English

Calendar Widget is a transparent desktop calendar widget for Windows 11 that shows your work shifts from Google Calendar (read-only access), calculates monthly earnings from rates you enter, and sends Windows reminders. It runs entirely on your computer. See the privacy policy.
