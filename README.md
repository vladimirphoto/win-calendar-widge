# Calendar Widget для Windows 11

Прозрачное окно без рамки в стиле Windows 11: сетка месяца, ваши смены и события из Google Календаря.
Живёт в трее, может запускаться вместе с Windows (отключается в один клик).

## Получить exe

Результат: один файл `CalendarWidget.exe`. Устанавливать ничего не нужно, он запускается двойным кликом
из любой папки (положите, например, в `Документы\CalendarWidget`).

**Способ 1. Двойной клик (Windows).** Распакуйте архив и запустите `build-exe.bat`.
Если Node.js нет, скрипт поставит его через winget (потом запустите `build-exe.bat` ещё раз).
Через несколько минут откроется папка `dist` с готовым `CalendarWidget.exe`.

**Способ 2. Без установки чего-либо.** Загрузите папку на GitHub (приватный репозиторий подойдёт).
Сборка запускается сама после каждого изменения (или вручную: вкладка **Actions → Build exe → Run workflow**).
Готовый `CalendarWidget.exe` лежит в **Releases** (тег `latest`).

Для разработки: `npm install`, затем `npm start`.

Автозапуск с Windows работает из собранного exe: переместив файл в другую папку, один раз выключите
и снова включите «Запускать при старте Windows», чтобы обновился путь.

## Вход в Google Календарь

Нажмите **«Войти через Google»** (внизу виджета или в ⚙), откроется браузер, разрешите доступ «только чтение».
Больше ничего вводить не нужно: Client ID и Client secret уже вшиты в приложение (`src/google-client.js`).

Приложение запрашивает единственное право: `calendar.readonly`. Токен обновления хранится на диске
в зашифрованном виде (Windows DPAPI через Electron safeStorage), пароля Google в виджете нет.

Так как вшитый secret лежит внутри exe, репозиторий лучше держать приватным, а exe не раздавать посторонним.
Чтобы использовать другой OAuth-клиент, замените значения в `src/google-client.js` и пересоберите exe.

**Старые настройки.** Если раньше вы вводили свой Client ID, он продолжит использоваться, вход не слетит.
Старый Client secret из `settings.json` при первом запуске переносится в зашифрованный `secret.bin`,
из `settings.json` он удаляется.

Если вход через вшитый клиент не работает («доступ заблокирован»), в Google Cloud Console →
Google Auth Platform → Audience добавьте свой e-mail в **Test users** или нажмите **Publish app**.

## Заработок, следующая смена, уведомления

- **Заработок.** В ⚙ → «Заработок» для каждой студии (определяется по цвету метки) задаётся ставка за смену в тенге.
  Сумма за отображаемый месяц показана под названием месяца: «12 смен · 300 000 ₸». Считаются только смены
  (см. «Что считать сменой»). Ставки можно менять в любой момент.
- **Следующая смена** показана над сеткой: «Следующая: завтра, 10:00, Студия 1». Во время смены строка
  меняется на «Сейчас: …, до 22:00». Считается от сегодняшнего дня, даже если вы листаете другой месяц.
- **Уведомление Windows** за N часов до начала смены (по умолчанию за 2). Включается и настраивается в ⚙ → «Уведомления».
  Виджет должен быть запущен (он живёт в трее, скрытый тоже работает). Клик по уведомлению открывает виджет.
- **Автообновление** раз в 10 минут, плюс кнопка «Обновить», плюс обновление после выхода компьютера из сна.
- **Работа без интернета.** Последние загруженные события кэшируются на диск (в зашифрованном виде).
  Без сети виджет показывает их со статусом «Офлайн · данные от 14:05».
- **Возврат на сегодня.** Если вы листали календарь и ничего не нажимали 2 минуты, он сам возвращается на сегодняшнюю дату.

## Смены и цвета студий

Цвет берётся из метки события в Google Календаре. Если у события метки нет, берётся цвет самого календаря.
День со сменой тонируется цветом студии и получает снизу цветную полоску; если в один день смены в двух
студиях, полоска делится на цвета. Цвет есть и у полоски события в списке дня. В шапке показывается число смен за месяц.

По умолчанию сменой считается **каждое** событие. Если в календаре есть и личные события, откройте
⚙ → «Что считать сменой» и впишите слова из названий смен через запятую (например `студия, смена`).

## Управление

| Что | Как |
| --- | --- |
| Переместить | потянуть за шапку (где название месяца) |
| Месяц вперёд / назад | стрелки, колесо мыши по сетке, клавиши ← → |
| Скрыть | кнопка ✕ в шапке или клик по значку в трее |
| Автозапуск, поверх окон, закрепить положение | меню значка в трее или ⚙ |
| Прозрачность | ⚙ → ползунок |
| Выход | меню значка в трее → «Выход» |

Цвет акцента берётся из настроек Windows и меняется на лету; тёмная и светлая тема тоже подхватываются автоматически.

## Где лежат данные

`%APPDATA%\win-calendar-widget\` содержит `settings.json` (настройки, ставки, положение окна), `token.bin` (зашифрованный токен), `events-cache.bin` (зашифрованный офлайн-кэш событий) и `secret.bin` (только если раньше вводили свой Client secret).
Чтобы полностью сбросить виджет, закройте его и удалите эту папку.

## Структура

```
src/main.js            окно, трей, автозапуск, OAuth, запросы к Google, офлайн-кэш, уведомления
src/google-client.js   вшитые Client ID / secret
src/preload.js         безопасный мост между окном и main
src/renderer/          интерфейс (index.html, styles.css, renderer.js)
build/gen-icon.js      генератор иконки (запускается автоматически)
```
