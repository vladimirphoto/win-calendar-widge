# Calendar Widget для Windows 11

Прозрачное окно без рамки в стиле Windows 11: сетка месяца, ваши смены и события из Google Календаря.
Живёт в трее, может запускаться вместе с Windows (отключается в один клик).

## Получить exe

Результат: один файл `CalendarWidget.exe`. Устанавливать ничего не нужно, он запускается двойным кликом
из любой папки (положите, например, в `Документы\CalendarWidget`).

**Способ 1. Двойной клик (Windows).** Распакуйте архив и запустите `build-exe.bat`.
Если Node.js нет, скрипт поставит его через winget (потом запустите `build-exe.bat` ещё раз).
Через несколько минут откроется папка `dist` с готовым `CalendarWidget.exe`.

**Способ 2. Без установки чего-либо.** Загрузите папку на GitHub (приватный репозиторий подойдёт).
Сборка запускается сама после каждого изменения (или вручную: вкладка **Actions → Build exe → Run workflow**).
Готовый `CalendarWidget.exe` лежит в **Releases** (тег `latest`).

Для разработки: `npm install`, затем `npm start`.

Автозапуск с Windows работает из собранного exe: переместив файл в другую папку, один раз выключите
и снова включите «Запускать при старте Windows», чтобы обновился путь.

## Вход в Google Календарь

Нажмите **«Войти через Google»** (внизу виджета или в ⚙), откроется браузер, разрешите доступ «только чтение».
Больше ничего вводить не нужно: Client ID и Client secret уже вшиты в приложение (`src/google-client.js`).

Приложение запрашивает единственное право: `calendar.readonly`. Токен обновления хранится на диске
в зашифрованном виде (Windows DPAPI через Electron safeStorage), пароля Google в виджете нет.

Так как вшитый secret лежит внутри exe, репозиторий лучше держать приватным, а exe не раздавать посторонним.
Чтобы использовать другой OAuth-клиент, замените значения в `src/google-client.js` и пересоберите exe.

**Старые настройки.** Если раньше вы вводили свой Client ID, он продолжит использоваться, вход не слетит.
Старый Client secret из `settings.json` при первом запуске переносится в зашифрованный `secret.bin`,
из `settings.json` он удаляется.

Если вход через вшитый клиент не работает («доступ заблокирован»), в Google Cloud Console →
Google Auth Platform → Audience добавьте свой e-mail в **Test users** или нажмите **Publish app**.

## Заработок, следующая смена, уведомления

- **Заработок.** В ⚙ → «Заработок» для каждой студии (определяется по цвету метки) задаётся ставка по умолчанию за смену в тенге.
  Если в конкретный день вы заработали другую сумму (зависит от клиентов), откройте этот день и впишите сумму в поле «₸» на карточке смены:
  она заменит ставку только для этого дня и этой студии. Пустое поле = ставка по умолчанию. Под названием каждой студии (оно берётся из календаря) показано ваше имя из поля «Что считать сменой». Кнопка **«Очистить заработок»** стирает все ставки и суммы по дням (нужно нажать дважды).
  Сумма за отображаемый месяц показана справа от даты над списком дня: «Четверг, 22 Октября … Заработок: 300 000 ₸». Считаются только смены
  (см. «Что считать сменой»). Ставки можно менять в любой момент.
  Переключатель **«Показывать заработок за»** в ⚙ → «Заработок»: «Весь месяц» / «1–15» / «16–конец». Смены 1–15 оплачиваются 15-го этого месяца, смены 16–конец — 1-го следующего;
  переключатель показывает, сколько придёт в каждую выплату (по дате начала смены); подпись над списком меняется на «Заработок 1–15» или «Заработок 16–31».
  **Аванс:** в ⚙ → «Аванс» включите «Учитывать аванс» и внесите суммы за 1–15 и за 16–конец для открытого в календаре месяца. Аванс вычитается из заработка: под суммой появляется строка «аванс −10 000 ₸ · к выплате 40 000 ₸» (при «Месяц» вычитаются оба). Кнопка «Очистить аванс» стирает его (нужно нажать дважды). С наступлением нового месяца аванс прошлых месяцев удаляется сам. Выключатель аванс не стирает, а только скрывает.
- **Панели в календаре** (⚙ → «Панели в календаре», каждая включается отдельно, по умолчанию выключены; работают по вашим сменам):
  - *Цель по заработку*: вы задаёте сумму на месяц, под сеткой тонкая полоска. Тёмная часть — уже отработанные смены, светлая — запланированные (подсказка при наведении), сверху «Заработано X из Y» и «осталось Z».
  - *По студиям за месяц*: за открытый месяц у каждой студии число смен и сумма (по ставкам и суммам за день).
  - *Серия выходных*: дни без ваших смен, начиная с сегодняшнего, получают пунктирную рамку; под сеткой «Серия выходных: 28 окт – 8 нояб (12 дней)». Минимальная длина серии настраивается (2–7, по умолчанию 3).
- **Следующая смена** отдельной строкой не показывается (убрана по просьбе), но по ней работают уведомления и подсказка в трее.
- **Уведомление Windows** за N часов до начала смены (по умолчанию за 2). Включается и настраивается в ⚙ → «Уведомления».
  Виджет должен быть запущен (он живёт в трее, скрытый тоже работает). Клик по уведомлению открывает виджет.
  Смены «на весь день» (без времени начала) напоминают накануне в заданное время, по умолчанию 20:00 («Завтра смена: …»); время меняется в ⚙ → «Уведомления», для этого нужны слова в «Что считать сменой».
  Кнопка **«Уведомить сейчас»** показывает тестовое уведомление. Если его не видно, проверьте режим «Не беспокоить» в Windows.
- **Автообновление** раз в 10 минут, плюс обновление при нажатии «Сегодня» (отдельной кнопки «Обновить» нет), плюс обновление после выхода компьютера из сна.
- **Работа без интернета.** Последние загруженные события кэшируются на диск (в зашифрованном виде).
  Без сети виджет показывает их со статусом «Офлайн · данные от 14:05».
- **Возврат на сегодня.** Если вы листали календарь и ничего не нажимали 2 минуты, он сам возвращается на сегодняшнюю дату.

## Обновления

Виджет сам проверяет новую версию через 20 секунд после запуска и затем каждые 6 часов. Если версия новее,
он скачивает `CalendarWidget.exe`, проверяет размер и контрольную сумму SHA-256, закрывается и запускается
уже новой версией (занимает несколько секунд). Данные и настройки сохраняются.
Вручную: ⚙ → «Обновления» → **«Проверить обновления»** или пункт в меню значка в трее.
Автоустановку можно выключить в ⚙: тогда придёт уведомление, а ставить вы будете сами одной кнопкой.

Никаких токенов и секретов настраивать не нужно: репозиторий публичный, виджет берёт релиз `latest` прямо из него.

**Как выпустить обновление.** Внесите изменения и сделайте push в `main`. GitHub Actions соберёт exe,
выставит версию `1.0.<номер сборки>` и обновит релиз `latest`. Виджеты у всех подтянут его сами.
Ничего вручную менять не надо.

**Условия.**
- Обновляется только собранный exe (из исходников `npm start` обновляться не будет).
- Файл нужно запускать из папки, куда можно записывать (Документы, Рабочий стол), не из `Program Files`.
- Обновления берутся из Releases этого же публичного репозитория, имя задано в `src/update-config.js`.
  Репозиторий должен оставаться публичным, иначе виджет напишет «Релиз не найден».
- Первую версию с автообновлением нужно поставить вручную, дальше обновления идут сами.

## Смены и цвета студий

Цвет берётся из метки события в Google Календаре. Если у события метки нет, берётся цвет самого календаря.
День со сменой тонируется цветом студии и получает снизу цветную полоску; если в один день смены в двух
студиях, полоска делится на цвета. Цвет есть и у полоски события в списке дня. В шапке показывается число смен за месяц.

Пока поле ⚙ → «Что считать сменой» пустое, виджет остаётся **чистым календарём**: без отметок смен, точек студий,
списка событий дня, заработка и напоминаний (и без демо-примеров, даже если вы ещё не вошли в Google). Впишите своё имя так, как оно написано в названиях смен (можно несколько слов через запятую),
и ваши смены подсветятся цветом студии.

Уведомление о смене выглядит так: «Завтра смена на {точка}», ниже «Прекрасного дня!». Точка берётся из названия календаря студии без «В!Ф Алматы на» (например, «Маркова»).

## Управление

| Что | Как |
| --- | --- |
| Переместить | потянуть за узкую полоску сверху окна (с серым «язычком») |
| Месяц вперёд / назад | стрелки, колесо мыши по сетке, клавиши ← → |
| Скрыть | кнопка ✕ в шапке или клик по значку в трее |
| Автозапуск, поверх окон, закрепить положение | меню значка в трее или ⚙ |
| Прозрачность | ⚙ → ползунок |
| Тема: светлая / тёмная / стекло | ⚙ → переключатель рядом с «Готово» |
| Выход | меню значка в трее → «Выход» |

Цвет акцента берётся из настроек Windows и меняется на лету. Пока тема не выбрана вручную, виджет следует светлой/тёмной теме Windows.

Тема «Стекло» в духе iOS: скруглённая карточка с тенью, как в светлой и тёмной теме, светящийся ободок и размытые обои рабочего стола под ней. Степень размытия настраивается ползунком «Размытие стекла» (виден только при выбранном «Стекле»). Размывается именно картинка обоев (из них берётся текущий файл Windows), а не окна, лежащие под виджетом. Если обои прочитать не удалось, остаётся полупрозрачная карточка без размытия.

## Полное удаление

Перед удалением приложения откройте ⚙ → **«Данные приложения» → «Удалить все данные…»** и подтвердите.
Виджет отзовёт доступ в вашем аккаунте Google, уберёт автозапуск, сотрёт настройки, ставки, кэш и токен,
закроется и удалит всю свою папку в `%APPDATA%` (вместе с кэшем Chromium). Переключатель в окне подтверждения
позволяет заодно удалить и сам `CalendarWidget.exe`. Если оставить его выключенным, файл удалите вручную.
Временная папка распаковки portable-версии в `%TEMP%` Windows чистит сама.
Если виджет уже удалён вручную, доступ можно отозвать на myaccount.google.com/permissions.

## Где лежат данные

`%APPDATA%\win-calendar-widget\` содержит `settings.json` (настройки, ставки, положение окна), `token.bin` (зашифрованный токен), `events-cache.bin` (зашифрованный офлайн-кэш событий) и `secret.bin` (только если раньше вводили свой Client secret).
Чтобы полностью сбросить виджет, закройте его и удалите эту папку.

## Структура

```
src/main.js            окно, трей, автозапуск, OAuth, запросы к Google, офлайн-кэш, уведомления
src/google-client.js   вшитые Client ID / secret
src/updater.js         самообновление из GitHub Releases
src/update-config.js   откуда брать обновления
src/preload.js         безопасный мост между окном и main
src/renderer/          интерфейс (index.html, styles.css, renderer.js)
build/gen-icon.js      генератор иконки (запускается автоматически)
```
