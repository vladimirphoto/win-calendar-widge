Настройки

Впишите своё имя так, как оно написано в названиях смен (можно несколько слов через запятую). Пока поле пустое, виджет остаётся чистым календарём: без отметок смен, заработка и напоминаний. Чтобы скрыть чужие смены, включите «Показывать только мои смены».

Заработок

Ставка по умолчанию за одну смену в тенге, отдельно для каждой студии. Если в какой-то день вы заработали другую сумму, впишите её в карточке смены этого дня: она заменит ставку. Считаются только ваши смены; сумма за месяц стоит справа от даты. Под названием студии показано ваше имя из поля «Что считать сменой».

Студии появятся после первой синхронизации с календарём.

Стирает все ставки и суммы по дням, чтобы внести их заново.
